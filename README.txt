好好收纳室 · Claude 手帐档案

使用方式
1. 解压 ZIP。
2. 把 index.html 上传到 GitHub 仓库（覆盖原来的入口文件即可）。GitHub Pages 会自动部署。
3. 打开网站，点击“导入 JSON”，选择 Claude 导出的 conversations JSON 文件。
4. 右上角“备份”可导出本机档案和聊天记录；“恢复”可导入本工具生成的完整备份。

包含
- 手帐风布局、手机适配和顶部标题/图标分离，避免挡字。
- Claude JSON 导入、聊天列表、消息搜索、长对话虚拟滚动。
- 双击对话标题可改名；消息可编辑、删除，或保存到 Memory。
- Memory、Projects、Profile、Artifacts、Skills 分类卡片，支持编辑和整理状态。
- 本地浏览器自动保存、完整 JSON 备份与恢复、对话多选删除。

重要说明
- 数据默认保存在当前浏览器的 localStorage 中，不会上传到服务器。清理浏览器数据或换设备前，请先导出备份。
- 网页无法直接读取或修改 Claude 官方账户中的记录；修改只作用于本工具保存的数据。
- 这是单页初版。对话编辑会修改当前工具内的数据副本；请先备份，再进行批量删除等操作。
