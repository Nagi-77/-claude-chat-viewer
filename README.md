# 好好收纳室 · Claude 手帐档案

这是一个纯本地运行的单文件网页，适合放进 GitHub Pages。无需安装依赖，也不会把聊天记录上传到服务器。

## 使用方法
1. 解压 ZIP。
2. 将 `index.html` 上传到 GitHub 仓库根目录（与仓库的 Pages 发布目录一致）。
3. 打开部署后的网站，在右上角选择「导入 JSON」，选择 Claude 导出的 `conversations.json`。
4. 数据会保存在当前浏览器的本地存储中。请定期点「备份」下载完整备份，尤其在清理浏览器数据或换设备前。

## 本版针对导出格式的适配
- 兼容 Claude 导出常见的 `chat_messages` / `messages` 数组。
- 保留消息原始字段；对话中的 `thinking`、`tool_use`、`tool_result` 分别显示，不与普通正文混在一起。
- 对空正文、附件消息不直接过滤，会显示占位提示。
- 再次导入时按对话 ID 和消息 ID 合并；已存在的消息不会重复追加。没有 ID 的消息会使用内容指纹作为备用识别方式。
- Memory、Projects、Profile、Artifacts、Skills 卡片和聊天数据都包含在完整备份里。

## 数据与兼容性说明
- 网页只在浏览器本地处理文件，不会主动上传聊天内容。
- 浏览器本地存储有容量限制；大型聊天记录可能占用较多空间。请定期导出完整备份。
- 浏览器数据不会自动跨设备同步。要迁移设备，请导出备份并在另一台设备恢复。
- Claude 未来可能调整导出格式。本版会尽量保留未知原始字段，但对完全不同的新结构仍可能需要更新适配。
- 修改或删除消息会影响本地档案副本，不会修改 Claude 账户里的原始聊天记录。
