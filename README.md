# 好好收纳室｜Claude 手帐档案

## 部署
1. 解压本压缩包。
2. 将 `index.html` 上传到 GitHub 仓库根目录。
3. 在仓库 Settings → Pages 中启用 GitHub Pages。
4. 打开生成的网址，点击「导入 JSON」，选择 Claude 导出的 `conversations.json`。

## 数据保存
- 聊天记录和卡片保存在当前浏览器的 IndexedDB 中，不会上传到服务器。
- 初次使用会尝试迁移旧版本留在 localStorage 的数据。
- 点击「备份」可导出完整 JSON 备份；请把备份文件另存到手机或云盘。
- 在同一设备、同一浏览器、同一网站地址下打开，才能读取原本的本地数据。更换设备/浏览器/网址后，请使用「恢复」导入备份。
- 清除浏览器网站数据会删除本地档案，因此不要把网页本地存储当作唯一备份。

## 导入兼容
支持 Claude 导出中常见的 `chat_messages`、`text`、`content`，并保留原始消息对象。对话中的 thinking、tool_use、tool_result 会单独展示；空正文和附件消息不会仅因正文为空而被过滤。后续导出可再次导入并按对话/消息 ID 合并。未知格式可能需要后续适配。

## 已知限制
这是纯前端本地工具。不同浏览器对 IndexedDB 容量的限制不同；大量附件本体若未包含在导出 JSON 中，网页无法凭空恢复附件文件。初次导入后请先导出一份完整备份并核对对话/消息数量。
